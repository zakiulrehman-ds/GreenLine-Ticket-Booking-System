# # GreenLine Ticket Booking System
**GreenLine Ticket Booking System** is an interactive web application designed for online bus ticket reservations, schedule tracking, and passenger booking management.
### Features
**Interactive Seat Selection:** Dynamic UI for selecting preferred seats in real-time.
**Route & Bus Search:** Filter schedules by departure station, destination, and timing.
**Booking Summary & Checkout:** Transparent ticket cost calculation and passenger details submission.
**Responsive Design:** Optimized user interface across desktop, tablet, and mobile browsers.
### Tech Stack
**Frontend:** HTML5, CSS3, JavaScript, jQuery
**Styling:** Custom CSS / Frameworks
**Version Control:** Git & GitHub
